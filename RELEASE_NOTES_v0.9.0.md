## App / UI
- **Ranked**, **Randomiser**, and **Pick one** in Music For... now share matched height, padding, font size and width/alignment.
- Existing v0.8.0 Music For... modes, Guide icons, home layout and bottom-nav icon language are retained.
- Existing artwork resolution order is retained: known artwork map → TheAudioDB → YouTube worker fallback.

## Compatibility
- Personal data key remains `atm-mobile-v01`.
- Artwork cache remains `atm-mobile-artwork-v2`.
- Service-worker cache bumped to `atm-mobile-v090`.
- YouTube Music remains the primary outbound listening link; Spotify remains secondary.

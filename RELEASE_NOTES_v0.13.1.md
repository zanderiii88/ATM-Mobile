# ATM Mobile v0.13.1

Released: 2026-09-16

## What changed
- Changed the bottom navigation icon for **Music For...** from the simple car icon to a **cassette tape** icon.
- Retained the v0.13.0 playlist/account integration, including ATM-owned YouTube Music + Spotify links.
- Bumped app metadata, version references and service-worker cache to v0.13.1.

## Scope
This is a small UI-only patch. The catalogue remains at **2,500 artists** and no recommendation logic, playlist URLs or user data storage keys were changed.

## Compatibility
- Existing favourites, Want To Explore, dislikes, notes and listening history remain compatible.
- No workbook update is required for this release.

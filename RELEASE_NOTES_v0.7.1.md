# Artists That Matter / ATM Mobile v0.7.1

Released: 2026-09-14

## Summary
Small UI refinement release on top of v0.7.0. Catalogue content is unchanged at 2,297 artists.

## What changed
- Kept the grouped home-page order introduced in v0.7.0.
- Tightened the **Discover & Explore** block for narrow phone screens so the first four discovery cards remain a compact 2-column cluster rather than stretching into one long vertical list.
- Changed the **Vibes** icon from a diamond to a waveform on the home card and in the bottom navigation.
- Redrew the **Music For...** icon set so the frying pan, car and bed are clearer and more distinguishable at phone size.
- Replaced the bottom-navigation glyphs with cleaner line icons for better consistency on mobile.
- Updated guide wording to reflect the Vibes waveform icon.
- Bumped app version and service-worker cache.

## Verified
- Catalogue/app count remains **2,297**.
- No catalogue entries were added, removed or duplicated in this patch release.
- Existing local data compatibility retained via the stable `atm-mobile-v01` storage key.
- Service-worker cache updated to `atm-mobile-v071`.

## Notes
This is a presentation/UI patch only. The workbook data is unchanged from v0.7.0.

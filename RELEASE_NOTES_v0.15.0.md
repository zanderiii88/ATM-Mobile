# ATM Mobile v0.15.0

Released: 2026-09-17

## Music For... mixtape expansion
- Added YouTube Music and Spotify links to all 20 newly curated Music For... selections supplied for this release.
- Shortened five labels for cleaner scanning: **Calm Down**, **Wake Up**, **Get Hyped**, **Going Out**, and **First Coffee**.
- Existing saved selections and imported backups using the previous labels migrate to the new names automatically.
- Added **Dancing… In The Pit** as a new recommendation-only Dancing option for hardcore, metalcore, post-hardcore, nu-metal, crossover and other mosh-friendly heavy music.
- All Music For... headings now start collapsed. After a user selects an option, that option’s parent section remains open while results are shown.
- Playlist URLs are stored without service tracking parameters.

## Home artwork
- Replaced the concert header banner with the approved alternate version. It preserves the dark monochrome crowd composition while changing the vocalist’s hair/profile so the figure reads as a more generic performer.

## Home / What’s New
- Refreshed the dismissible What’s New card to highlight the expanded Music For... mixtape library and Dancing… In The Pit.

## Preserved
- Six-button bottom navigation remains unchanged, including **Lucky**.
- Catalogue remains at **2,500 artists**.
- Similarity and recommendation logic are unchanged except for the new Dancing… In The Pit preset.
- Existing Road Trip and standalone ATM Mixtape links are unchanged.
- Personal data continues to use the stable `atm-mobile-v01` storage key.
- v0.12.1 mobile performance improvements and v0.14.0 usability cleanup are retained.
